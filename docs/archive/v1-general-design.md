# 志愿者管理系统 - 功能设计文档（当前实现版）

> 本文档以**当前代码实现**为准，描述系统现有功能和界面设计。
> 最后更新：2026-03-04

---

## 1. 整体布局

页面分为三层：**顶部导航栏 + 主内容区 + 底部 Footer**。

主内容区在首页为左右分栏：
- **左侧（约 65%）**：地图 + 筛选工具栏
- **右侧（约 35%）**：统计摘要 + 搜索框 + 志愿者列表

---

## 2. 顶部导航栏（Header）

```
┌──────────────────────────────────────────────────────────────────┐
│ 志愿者管理系统  全球志愿者可视化平台                               │
│                      [首页]  [个人中心]  [审核中心]               │
│                                            [登录] 或 [账号名·role] [退出] │
└──────────────────────────────────────────────────────────────────┘
```

- **未登录**：显示 [登录] 按钮，点击弹出登录 Modal
- **已登录**：显示账号名 + role 标签 + [退出登录]
- **导航项**：首页 / 个人中心 / 审核中心（点击个人中心/审核中心若未登录则弹登录框）

---

## 3. 首页（Home）

### 3.1 左侧：地图 + 筛选工具栏

**筛选工具栏**（地图上方）：
```
状态: [全部▼]   方向: [全部▼]   热门省份: [全部▼]   地区/省份: [单选][多选]   [重置]
```

- **状态**：全部 / 在职 / 不在职
- **方向**：全部 / 翻译 / 校对 / 管理 / 技术
- **热门省份**：全部 / 北京（→北京市）/ 上海（→上海市）/ 深圳（→广东省）
- **地区/省份**：单选或多选模式切换，与地图联动
- **重置**：清空所有筛选条件

**地图（react-leaflet）**：
- 支持点击省份/地区触发筛选
- 左上角浮动控制栏：`[+][-][◎][↻]`
  - `◎`：展开/折叠快速聚焦面板（中国大陆 / 中国台湾 / 东南亚 / 美国 / 欧洲）
  - `↻`：重置地图视图 + 清空地区/省份筛选
- 台湾省归一化为"台湾省"

### 3.2 右侧：摘要 + 搜索 + 志愿者列表

**筛选摘要**：
```
筛选摘要                    X 条
┌──────────┬──────────┬──────────┐
│ 匹配志愿者│  在职占比 │ 总服务时长│
│    N 人   │   XX%   │  XXXh    │
└──────────┴──────────┴──────────┘
[状态: 全部] [方向: 翻译] [省份: 北京市] ...
```

**搜索框**：支持姓名 / 英文名 / ID / 省份，250ms debounce

**志愿者列表**：紧凑卡片，桌面端 2 列排列，点击卡片打开详情弹窗

---

## 4. 志愿者详情弹窗（VolunteerDetailModal）

点击任意志愿者卡片触发，Modal 显示：

- 志愿者基本信息（中英文姓名、ID、状态、地区/省份、服务方向）
- NPS 服务记录列表（分页，每页 8 条，"查看更多"加载）
- **已登录用户**：可展开提交 NPS 申请表单（为该志愿者提交 create 申请）

---

## 5. 个人中心（Me Center）

点击导航"个人中心"进入，根据账号 role 显示不同内容：

### 5.1 普通用户（role: user / b_admin / a_admin）

```
我的个人中心                              [刷新面板]
──────────────────────────────────────────────────
账号信息：姓名、邮箱、role
志愿者档案：ID、状态、地区、服务方向
──────────────────────────────────────────────────
我的 NPS 服务记录（分页，每页 8 条）
┌──────────────────────────────────────────────┐
│ 日期 | 类型 | 时长 | 描述 | [编辑] [删除]    │
└──────────────────────────────────────────────┘
[查看更多记录]

[+ 提交 NPS 申请]（点击展开表单）
  表单字段：服务日期 / 服务类型（翻译/校对/管理/技术）/ 时长 / 描述
```

- **编辑**：提交 update 类型申请，需审核后生效
- **删除**：提交 delete 类型申请，需审核后生效
- 未绑定 volunteerId 的账号无法提交申请

### 5.2 系统管理员（role: admin）

进入 **AdminCenter**，功能：
- 账号列表查看 / 搜索
- 创建单个账号 / 批量 CSV 导入
- 批量生成志愿者账号（指定密码）
- 账号详情编辑（姓名、邮箱、role、volunteerId 等）
- 删除账号
- 系统重置

---

## 6. 审核中心（Review Center）

审核员（b_admin / a_admin / admin）可见：

### 6.1 待审申请

- 列表显示所有 pending 状态申请
- 申请类型：create / update / delete
- 申请信息：申请人、目标志愿者、changes 字段列表
- 操作：单条[通过] / [拒绝]（可填写审核意见）+ 批量通过

### 6.2 可视化图表

- 按 serviceType / volunteerId 分组的柱状图
- 图表模式切换：Create / Change / Delete
- 点击柱子高亮对应申请

### 6.3 已处理历史

- 显示已通过/已拒绝的申请记录
- 可折叠（[隐藏已处理]）

---

## 7. NPS 申请流程

```
志愿者提交申请（create/update/delete）
    ↓
ServiceApplication 入库（status: pending）
    ↓
审核员在审核中心审核
    ↓
通过 → NonProjectService 同步（创建/修改/标记删除）+ AuditLog 记录
拒绝 → 申请标记 rejected + AuditLog 记录
```

---

## 8. 权限体系

| role | 说明 | 可访问 |
|------|------|--------|
| user | 普通志愿者 | 首页、个人中心（NPS 申请） |
| b_admin | 审核员（部长级） | + 审核中心 |
| a_admin | 高级管理员 | + 审核中心（更高权限） |
| admin | 系统开发者 | + AdminCenter（账号管理） |

- 账号通过 admin 手动创建（无注册功能）
- JWT 认证，前端 AuthContext 统一管理登录状态

---

## 9. 服务类型（当前有效）

`翻译 / 校对 / 管理 / 技术`

## 10. 数据模型概要

| 模型 | 关键字段 |
|------|---------|
| Volunteer | id(PG-xxxx), chineseName, englishName, status, region, province, services[] |
| Account | email, passwordHash, name, role, volunteerId, isActive |
| NonProjectService | serviceId, volunteerId, serviceType, duration, serviceDate, description, isActive |
| ServiceApplication | applicationId, applicationType, volunteerId, changes[], submittedBy, status, reviewNote |
| AuditLog | 操作类型、操作人、目标 ID、时间戳 |
