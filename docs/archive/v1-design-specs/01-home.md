## 地区层级设计（统一方案）

当前问题：`region`（大区）和 `province`（省份）是两个独立筛选，概念上有歧义。

### 新层级模型

```
位置层级
│
├── 中国大陆（聚合标签，当任意大陆省份被选中时作为摘要显示）
│   ├── 东北  [辽宁 吉林 黑龙江]         <- 将来可加的子区标签
│   ├── 华北  [北京 天津 河北 山西 内蒙古]
│   ├── 华东  [上海 江苏 浙江 安徽 ...]
│   ├── 华南  [广东 广西 海南]
│   ├── ...
│   └── 其他省份
│
├── 台湾省
├── 香港 / 澳门
├── 美国
├── 欧洲
├── 东南亚
└── 其他
```

### 筛选器交互

- 省份（北京、上海、广东…）和其他国家/地区（美国、欧洲…）**并列展示**
- 「中国大陆」= 快捷全选所有大陆省份（后端过滤 `region: MAINLAND`）
- 选中具体省份 = 后端过滤 `province IN [...]` + `region: MAINLAND`
- 未来「东北」标签 = `province IN [辽宁, 吉林, 黑龙江]` + `region: MAINLAND`

### 热门省份列表（修正）

| 原来 | 修正 | 原因 |
|---|---|---|
| 北京 | 北京 | 正确 |
| 上海 | 上海 | 正确 |

| — | 台湾省 | 新增（与大陆并列） |

## 方向多选方案

当前：单选 `homeService: string`
目标：多选 `homeServices: string[]`

### 触发方式（收起式下拉）

```
方向  [翻译 校对 ▼]          <- 已选项摘要 + 展开箭头
      ┌─────────────────┐
      │ ☑ 翻译  ☑ 校对  │
      │ □ 管理  □ 技术  │
      └─────────────────┘
```

- 无选中时显示「全部」
- 多选时显示已选名称，超出时显示「已选 N 项」
- 后端过滤使用 `services: { hasSome: [...] }`（已支持）

## Active Filters 显示方案

```
┌─────────────────────────────────────────────────────────┐
│  [在职 ×]  [翻译 ×]  [校对 ×]  [北京 ×]  [+3 更多 ▼]  │
│                                                         │
│  点击 "+3 更多" 展开：                                   │
│  [在职 ×]  [翻译 ×]  [校对 ×]  [北京 ×]                │
│  [上海 ×]  [广东 ×]  [美国 ×]                           │
└─────────────────────────────────────────────────────────┘
```

- 默认显示前 **3** 个筛选 chip
- 剩余显示 `+N 更多`，点击展开内联显示全部
- 每个 chip 有 `×` 单独取消
- 总重置按钮在 filter panel 底部
