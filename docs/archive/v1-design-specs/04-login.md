## 关键细节

| 元素 | 值 |
|---|---|
| 卡片宽度 | `max-w-md` (28rem) |
| Logo 图标 | `h-14 w-14` 圆角渐变 teal→emerald |
| 提交按钮 | `variant="default"` `size="lg"` 全宽 |
| 密码字段 | 内置显示/隐藏切换 (Eye / EyeOff) |
| 错误状态 | 输入框 `error` prop 变红边框 |
