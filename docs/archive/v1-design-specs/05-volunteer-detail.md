## 关键细节

| 元素 | 值 |
|---|---|
| 头像尺寸 | `h-20 w-20` rounded-[1.5rem] |
| 活跃度 badge | `HIGH`/`MEDIUM`/`LOW` → success/warning/outline |
| 时长显示颜色 | `text-teal-600` |
| textarea | 手写 Tailwind，与 Input 风格一致 |
