## 关键交互

| 操作 | 效果 |
|---|---|
| `+ 提交服务记录` | 切换展开/收起提交表单 |
| `修改（提交审核）` | 在该条记录下方展开编辑表单 |
| `删除（提交审核）` | 直接提交删除申请（不弹窗） |
| `撤回` | 弹 confirm 二次确认后撤回 |
| `清空我的申请记录` | 双重 confirm 后批量隐藏 |
| `重新提交` | 预填表单并展开 |
