## 关键交互

| 操作 | 效果 |
|---|---|
| `[通过]` / `[驳回]` (列表行内) | 直接提交审核，无需进入图表 |
| 点击图表色块 | 弹出该志愿者+分类的申请明细 Modal |
| `[一键通过当前图全部]` | 批量审批当前 chartMode 的所有申请 |
| 点击已审核记录 | 弹出变更明细 Modal |
| `[清空列表]` | 前端隐藏已审核记录（不删数据） |
