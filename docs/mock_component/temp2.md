## 📌 **用户菜单展开组件**

### **基础展开菜单**
```ascii
┌──────────────────┐
│ 个人中心          │
│ 我的服务记录      │
│ 设置              │
│ ──────────────── │
│ 退出登录          │

```
- **标准菜单**：4个选项 + 分隔线
- **简洁样式**：无边框阴影，纯文本列表

## 💡 **在PPT中的使用建议**

1. **组合使用**：
   ```
   初始状态：┌─────────────────────────────────────────────┐
             │ 🌐 志愿地图  [👤 张三 (VM-0456) ▼]         │
             └─────────────────────────────────────────────┘
   
   点击后：  ┌─────────────────────────────────────────────┐
             │ 🌐 志愿地图  [👤 张三 (VM-0456) ▼]         │
             │                      ┌──────────────────┐  │
             │                      │ 个人中心          │  │
             │                      │ 我的服务记录      │  │
             │                      │ 设置              │  │
             │                      │ ──────────────── │  │
             │                      │ 退出登录          │  │
             │                      └──────────────────┘  │
             └─────────────────────────────────────────────┘
   ```

2. **交互动画**：
   - 菜单从箭头下方滑出
   - 菜单项逐个淡入
   - 悬停时项目高亮

3. **点击反馈**：
   - 点击"个人中心" → 菜单收起，页面跳转
   - 点击空白处 → 菜单收起
   - 点击"退出" → 确认弹窗

---

这个单独的菜单组件方便你在PPT中做**动态演示**，可以展示菜单的展开/收起、项目悬停、点击跳转等交互效果。
