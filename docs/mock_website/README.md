# 🗺️ 志愿者管理系统 - 交互原型与设计文档

这是一个基于 Markdown 链接跳转的 **交互式设计演示项目**，用于向设计团队提供明确的设计指导，并向甲方展示和确认预期效果。

## 🎯 项目目标

- **设计指导**：为 UI/UX 设计人员提供清晰、可交互的界面流程与状态说明。
- **效果确认**：帮助甲方直观理解系统功能、用户旅程与交互逻辑。
- **轻量原型**：无需代码，仅通过 Markdown 文件与超链接模拟完整用户操作流程。

## 📁 项目结构

```
volunteer-map-mock/
├── README.md               # 项目说明（本文档）
├── index.md                # 网站入口页（跳转至公开主页）
└── public/                 # 未登录用户（Public）相关页面
    ├── 01_home_logged_out.md   # 公开主页（默认中国视图）
    ├── 02_shanghai_selected.md # 上海市志愿者列表页
    └── 03_login_page.md        # 登录页面
```

## 🧭 使用指南

### 如果你是**设计人员**：
- 请按顺序浏览各页面，理解界面布局、状态切换与交互逻辑。
- 每个页面均包含 **设计说明** 和 **设计决策与备注** 部分，用于阐明设计意图。

### 如果你是**甲方或评审人员**：
- 请点击页面中的 **“可交互元素”** 链接，模拟用户操作。
- 跟随预设的用户旅程，体验系统在不同状态下的界面变化。
- 可在每页底部的 **设计决策与备注** 中提出疑问或建议。
