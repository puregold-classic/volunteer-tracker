## 🔍 **设计说明**

- **个人中心整合**：删除了单独的 `03_my_profile.md`，个人中心功能已整合到用户主页 `01_home_logged_in.md`
- **查看他人 vs 查看自己**：
  - **查看他人（本页面）**：只能查看信息，可为他人添加服务记录
  - **查看自己（用户主页）**：可修改头像/当前地区，管理自己的服务记录
- **权限清晰**：
  - 为他人添加记录需要审核
  - 不能修改他人的个人信息
  - 可以关注感兴趣的志愿者

## 📝 **设计决策与备注**

1. **页面功能简化**：
   - 查看他人详情页面专注于"查看"功能
   - 移除了个人中心的编辑和管理功能
   - 保持了为他人添加记录的核心功能

2. **导航优化**：
   - 顶部"个人中心"按钮直接链接到用户主页（自己的详情页）
   - 底部操作栏提供志愿者间的连续查看
   - 保持查看流程的连贯性

3. **数据一致性**：
   - 沿用Public部分的示例数据（张三VM-0456）
   - 服务记录与之前的统计信息保持一致
   - 地区信息基于志愿者的常驻地区

4. **关注功能**：
   - 简单的关注机制，便于后续查看
   - 增强社区互动性
   - 为后续的消息通知功能预留

5. **权限边界**：
   - 明确区分可操作和仅查看的内容
   - 为他人添加记录是User用户的核心权限
   - 个人信息修改保留给管理员

## 🚀 **交互流程**

### **从用户主页到查看他人**
1. 用户在自己的主页 `01_home_logged_in.md`
2. 点击地图上的地区或其他筛选方式
3. 进入 `02_profile_view_zhangsan.md` 查看他人详情
4. 可为他人添加记录或关注

### **从查看他人返回自己**
1. 在他人详情页 `02_profile_view_zhangsan.md`
2. 点击顶部"个人中心"按钮
3. 返回自己的主页 `01_home_logged_in.md`
4. 或点击底部"关闭"按钮返回

### **添加记录流程**
1. 在他人详情页点击"为TA添加记录"
2. 进入 `04_add_service_record.md`
3. 填写服务信息并提交
4. 返回他人详情页，看到新记录待审核
