## 🔍 **设计说明**

- **极致简化**：只保留最核心的四项服务信息（日期、类型、时长、描述）
- **状态驱动**：根据记录状态显示不同的操作按钮和说明
- **操作明确**：只有两个核心操作按钮：修改（编辑/申请修改/重新提交）和删除（删除/申请删除）
- **权限清晰**：通过按钮文字和说明明确操作权限

---

## 📝 **设计决策与备注**

1. **信息精简原则**：
   - 删除所有非核心信息（审核信息、附件、地点、人数等）
   - 保留服务记录的四个基本要素
   - 状态信息简化为图标+文字

2. **操作统一性**：
   - 无论什么状态，都是两个操作按钮
   - 按钮文字根据状态变化，但位置固定
   - 按钮下方有简短的权限说明

3. **状态识别**：
   - 通过状态图标和颜色快速识别
   - 通过按钮文字明确当前可执行的操作
   - 通过说明文字理解操作结果

4. **响应式设计**：
   - 简单布局，适合各种屏幕尺寸
   - 清晰的信息层次，便于阅读
   - 明确的视觉焦点（操作按钮）

5. **用户体验**：
   - 减少认知负担，只显示必要信息
   - 操作意图明确，减少误操作
   - 快速理解当前状态和可用操作

## 🚀 **交互流程**

### **查看详情**
1. 在记录列表点击"查看详情"
2. 进入简化详情页，看到核心信息
3. 根据状态看到相应的操作按钮
4. 点击操作或返回列表

### **修改记录**
- **待审核**：点击"编辑"直接修改
- **已确认**：点击"申请修改"提交修改申请
- **已拒绝**：点击"重新提交"修改后重新提交

### **删除记录**
- **待审核**：点击"删除"直接删除
- **已确认**：点击"申请删除"提交删除申请
- **已拒绝**：点击"删除"直接删除
