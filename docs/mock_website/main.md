## 一、顶部栏设计（简洁版）

### Public用户（未登录）：
```
┌─────────┬─────────────────────────────────────┬─────────────────────┐
│  🌐      │                                     │ [登录]    [注册]     │
│ 志愿地图 │     志愿者服务全球可视化平台        │                     │
└─────────┴─────────────────────────────────────┴─────────────────────┘
```

### User+用户（已登录）：
```
┌─────────┬─────────────────────────────────────┬─────────────────────┐
│  🌐      │                                     │ [👤 张三] (VM-0456) ▼│
│ 志愿地图 │     志愿者服务全球可视化平台        │ 个人中心 · 设置 · 退出│
└─────────┴─────────────────────────────────────┴─────────────────────┘
```

**管理员额外菜单项**：
- C级及以上：审核中心
- B级及以上：管理工具
- A级及以上：系统管理

### 2. **中部：主地图区域**

**地图特性**：
- 工具栏浮动于地图左上角
