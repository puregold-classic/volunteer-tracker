## 🔍 **设计说明**

- **状态延续性**：从主页点击上海市后，地图保持上海市高亮，右侧面板切换为列表视图
- **筛选上下文**：地区筛选自动锁定为"上海市"，其他筛选条件保持可调整状态
- **权限渐进**：
  1. Public用户：仅浏览列表基本信息
  2. 登录后：可点击卡片查看详情、使用筛选、联系志愿者
- **返回路径**：点击其他省份或重置按钮可返回主页重新选择
