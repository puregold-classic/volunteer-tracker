## 🔍 **设计说明**

- **统一入口设计**：登录和注册在同一页面展示，但注册功能有独立页面
- **表单验证**：
  - 邮箱格式验证
  - 密码非空检查
- **用户体验**：
  - 清晰的错误提示
  - 加载状态反馈
  - 记住登录状态选项（复选框）

---

## 📝 **设计决策与备注**

1. **安全设计**：
   - 密码输入显示为圆点
   - 登录失败有适当提示但不泄露具体信息
   - 防止暴力破解的尝试限制

2. **无障碍访问**：
   - 所有表单字段有明确的标签
   - 键盘导航支持（Tab键顺序）
   - 屏幕阅读器友好的提示

3. **响应式设计**：
   - 移动端：面板全宽度，减少内边距
   - 平板端：适当调整宽度
   - 桌面端：固定宽度居中显示

4. **登录成功处理**：
   - 成功后跳转到用户主页
   - 或返回原页面继续操作
   - 在Mock演示中可跳转到用户流程
