## 改版前主要问题

### 1. 整体气质偏“传统后台”，不够像现代社交产品
- 页面以浅底 + 普通白卡为主，视觉记忆点弱。
- 顶部导航、侧栏卡片、列表卡片都偏工具化，缺少社交平台常见的“沉浸式深色背景 + 高对比内容卡片”。
- 首页地图、筛选区、列表区之间的层级接近，第一眼不容易形成注意力主次。

### 2. 信息层级不够锋利
- 首页筛选器、摘要、搜索、列表都在争夺注意力，没有清晰“主舞台 / 次信息 / 辅助信息”的分层。
- 个人中心的统计、资料、操作、记录都使用相似视觉盒子，关键内容不够突出。
- 审核中心的图表、待处理项、已处理项虽然功能完整，但页面更像内部工具，缺少高密度但清晰的卡片组织方式。

### 3. 交互 affordance 不够强
- 按钮、标签、状态 pill 辨识度一般，激活态和 hover 态存在感不足。
- 卡片 hover 提示弱，不够像 X / Instagram 那种“能点、可展开、层级明确”的体验。
- 地图工具条和聚焦面板样式偏平，不够现代。

### 4. 可访问性与可读性还有空间
- 旧版很多灰色文字接近浅底，虽然不至于不可读，但对比度和聚焦感一般。
- 组件边界较轻，长页面里不够容易扫描。
- 缺少统一的高亮体系：主按钮、状态、标签、关键指标没有形成稳定视觉语言。

## 参考方向（X / Instagram 风格）
- 采用柔和暗色系作为全局舞台，内容卡片用半透明深色层承载。
- 强化“导航 / 主数据 / 内容列表 / 行为按钮”四级层次。
- 用胶囊按钮、轻玻璃感卡片、蓝青色高亮建立统一品牌感。
- 保持信息密度，但减少视觉噪音，让用户更快扫到重点。

## 已执行的关键 UI 改动

### 全局视觉系统
- 将首页、个人中心、审核中心核心容器升级为柔和暗色玻璃卡片。
- 建立统一边框、圆角、阴影、悬浮反馈语言。
- 将主高亮统一为蓝青渐变，弱化杂色，提升系统一致性。

### 顶部导航
- 将 header 改为半透明 sticky 顶栏，增强产品感与沉浸感。
- Logo 区增加品牌化容器，导航按钮改为胶囊式激活态。
- 登录状态和操作按钮统一为同一套深色 UI 语言。

### 首页
- 重做筛选栏：改为深色胶囊筛选控件，激活态更清晰。
- 强化地图舞台：地图容器、浮层控制区、底部工具栏整体暗色化，主次更清晰。
- 重做右侧摘要卡：匹配人数、在职占比、总服务时长改为更像社交 dashboard 的指标卡。
- 优化搜索框与志愿者列表容器，让列表更像可浏览内容流。
- 志愿者卡片改为暗色内容卡 + 更清晰的状态 pill / service tag。

### 个人中心
- 将资料头图、统计板、快捷操作、社区信息、NPS 记录统一为高层次卡片系统。
- 强化头像、昵称、标签与指标区的区分度。
- 表单、记录项、按钮统一为深色输入体系，减少旧版白底输入造成的割裂感。
- 后台管理模块（admin 区）同步套用统一视觉语言，避免页面局部风格断裂。

### 审核中心
- 将审核中心重构为更明显的双栏内容布局。
- 图表卡、审核项卡、已处理记录卡全部暗色化并提升 hover/active 反馈。
- 强化图表开关、一键通过按钮、详情弹层的一致性。
- 优化图表区网格线、bar 容器、legend，让它更接近现代运营/内容审核工具体验。

## 仍建议后续继续做的优化
1. 首页补一个更强的 hero 文案区，明确“平台价值 + 今日概览 + 快速入口”。
2. 给个人中心加入时间趋势图（近 30 天服务时长 / 申请状态），提升“社交化个人主页”感觉。
3. 审核中心可增加批量筛选（按状态 / 服务类型 / 提交人）和 sticky 工具条。
4. 地图可考虑引入更统一的暗色底图，进一步贴合整体主题。
5. 建议补一次真实移动端截图验证，确认深色控件在小屏下的密度与点击区域。
